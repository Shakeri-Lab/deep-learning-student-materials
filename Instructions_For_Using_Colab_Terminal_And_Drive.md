# Instructions For Using Colab Terminal And Drive


Created on 02/06/2026 by Tom Lever

Updated on 02/06/2026 by Tom Lever

Version 1.0.0


Navigate to "My Drive" in Google Drive.

Create a folder called `Assignment_1`.

Upload `hw1_script.py` and `hw1_impl.py`.

Navigate to https://colab.research.google.com/ .

Create a new notebook.

Open a file explorer by clicking on the folder icon in the left side bar.

Mount Drive by clicking the icon of a folder with the Google Drive symbol.

Permit your notebook to access your Google Drive files.

Explore the contents of `drive/MyDrive/Assignment_1`.

Click on Terminal and the bottom of your browser.

Confirm that the Present Working Directory of the Terminal is `/content` by running `pwd`.

Confirm that the folder drive exists by running `ls -al`.

Change directory to `Assignment_1` by running `cd drive/MyDrive/Assignment_1`.

Confirm that `hw1_script.py` and `hw1_impl.py` exist by running `ls -al`.

Run `python hw1_script.py`.
